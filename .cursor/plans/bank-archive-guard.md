# 入库保护

状态：已完成

## 目标

远程命中写入本地时，不覆盖已有完整题；可关闭自动入库；字母答案转成选项正文。管理页导入、按 index 编辑仍可覆盖。不改 `POST /search` 返回格式。

## 步骤

- [x] 抽出入库规则：`skipIfExists`、字母/判断答案规范化
- [x] 油猴：开关默认开，归档带 `skipIfExists`，日志区分新增/跳过/补全
- [x] 用合成数据验证新增、跳过、补全、字母转换

## 完成标准

- 默认开启自动入库；关闭后远程命中不写本地
- 本地已有答案的题不会被远程结果覆盖
- 无答案的同题干会被补全
- `A/B` 或 `对/错` 存成选项正文
- 管理页导入仍按题干更新
